# Decisions

Why Patchcord is the way it is: one decision a file (an ADR). Before a change that touches one of them, read it; to change one, write a new ADR that supersedes it, and mark the old one so.

General rules live in [principles](../principles.md). New ADRs start from [the template](0000-template.md).
